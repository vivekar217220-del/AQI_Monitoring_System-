# AQI_Monitoring_System-
An IoT-Based Air Quality Monitoring System using MQ-7 (CO), DHT11 (Temperature &amp; Humidity), and simulated PM2.5 values to estimate AQI. It provides real-time air quality indications through an RGB LED module, buzzer alerts, and OLED display. Currently working on Wi-Fi-based data sharing and a web dashboard for real-time AQI monitoring and analysis.
